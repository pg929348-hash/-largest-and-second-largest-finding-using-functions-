
🔍 Second Largest Finder

📌 About
This project helps you find the largest and second largest number from a list. It works for any order of numbers, whether ascending or descending.

✨ How It Works
- 🚀 Starts by assuming the smallest possible value for both largest and second largest
- 👀 Goes through each number in the list one by one
- 👑 If a new number is bigger than the current largest, the old largest becomes second largest and new number becomes largest
- 🥈 If a number is smaller than largest but bigger than second largest, it becomes the new second largest
- 🔁 Duplicate values are ignored for second largest

✅ What It Handles
- 📈 Normal lists like 1, 2, 3, 4, 5
- 📉 Reverse lists like 5, 4, 3, 2, 1
- 👯 Duplicate values like 5, 5, 3
- 🔢 Only two numbers
- 💯 All same numbers case

🎯 Output
It always gives you two results -> The biggest number and the second biggest number.

💡 Use Case
Perfect for practicing logic building, interviews, and basic DSA problems.
